# The Grim Gardener: DST Farm Planner

A farm planner for Don't Starve Together. Enter the season, day and your seeds, and it lays out a plot whose tiles feed themselves.

Static site: `index.html` + `img/`. No build step. Served with GitHub Pages (Settings → Pages → Deploy from a branch → root).

Unofficial fan tool, not affiliated with Klei Entertainment. Game art belongs to Klei Entertainment; pictures and numbers come from the Don't Starve Wiki.
